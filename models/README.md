# Моделі YOLO

Покладіть сюди ONNX-модель YOLO, яку використовує застосунок.

Очікувана назва за замовчуванням:

```text
models/yolov8n.onnx
```

Можна використати інший файл, якщо змінити `detection.model_path` в `app_config.toml`.

Для цього проєкту підходить COCO-сумісна YOLO-модель, у якій є класи:

- `person`
- `dog`
